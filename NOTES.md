# Портновский дом Троицкой — отчёт по сайту

## Сделано
- `index.html` — разметка сайта: header/навигация, hero, «История», «Услуги», «Мастерство» (галерея-текстуры), «Доверие», форма записи → WhatsApp, «Оплата» (информационная), «Контакты», footer.
- `styles.css` — все токены (цвета, шрифты, радиусы, отступы, тени) объявлены в `:root` как CSS custom properties; остальной CSS использует только `var(--...)`, без хардкода hex вне `:root`. Адаптив до 360px, `:focus-visible`, `prefers-reduced-motion` учтён в CSS (плавный скролл и reveal-анимации отключаются).
- `script.js` — мобильное меню, тень хедера при скролле, сигнатурная анимация «прошивки» в hero, reveal-on-scroll через IntersectionObserver, форма записи собирает имя/телефон/комментарий и открывает `https://wa.me/79852108806?text=...` в новой вкладке. Все анимации проверяют `matchMedia("(prefers-reduced-motion: reduce)")` и отключаются при включённой настройке.
- `NOTES.md` — этот файл.

## Дизайн-решения
- Палитра: тёплый песочный фон (`--color-bg #E7DECD`), эспрессо-чернила (`--color-ink`), оксблад/бордовый акцент кожи (`--color-oxblood`), античная бронза как сигнатурный акцент (`--color-bronze`), тёмная секция «эспрессо» (`--color-ink-deep`) для «Доверия» и footer — ритм светлого/тёмного вместо сплошного кремового фона.
- Типографика: display — Fraunces (мягкий, «ремесленный» serif, не классический high-contrast didone), body — Work Sans.
- Сигнатурный визуальный элемент: рисованная SVG-«прошивка» (стежок) под заголовком hero с анимацией «протягивания нити» (отключается при reduced motion); упрощённая версия того же мотива использована как пунктирная окантовка эмблемы-печати в шапке/подвале — единый визуальный язык, не растиражированный по всей странице.
- Галерея сделана полностью на CSS-паттернах (радиальные/конические градиенты, повторяющиеся линии) без внешних фото/стоков — по требованию брифа.

## Допущения (домыслено за пределами предоставленных фактов)
- Точный текст истории/подхода к работе обобщён («индивидуальный подход», «запись предварительная») — конкретная биография мастера(ов) не выдумывалась, так как в брифе её не было.
- Часы работы НЕ указаны нигде на сайте конкретными цифрами — вместо этого везде фраза «строго по предварительной записи, время уточняется по телефону/WhatsApp», так как реальных часов работы в брифе не было.
- Рейтинг и число отзывов на 2ГИС в брифе не были даны, поэтому в блоке «Доверие» использованы только подтверждённые факты (1999 год основания, 25+ лет, присутствие в 2ГИС и WhatsApp) — никакой рейтинг/количество отзывов не выдуманы.
- Реквизиты для перевода в разделе «Оплата» не публикуются на сайте (только описан способ «перевод по номеру телефона после согласования цены мастером») — конкретный номер для перевода не был предоставлен и не должен вводиться на публичном сайте без ведома владельца.

## Требует решения (вопросы для владельца бизнеса/студии)
1. Реальный рейтинг и количество отзывов на 2ГИС — если владелец хочет их показать, нужно дать точные актуальные цифры (это данные, которые быстро устаревают, лучше обновлять вручную, а не выдумывать).
2. Фактический режим/часы приёма (даже «по записи» обычно имеет диапазон дней/часов) — уточнить и добавить в раздел «Контакты».
3. Реквизиты для перевода по номеру телефона (сам номер для перевода, если отличается от рабочего телефона) — уточнить у владельца перед публикацией.
4. Короткая проверенная история/биография мастера(ов) дома Троицкой, если владелец захочет заменить обобщённый текст на конкретные факты (имена, награды, специализация).
5. Реальные фотографии работ ателье — сейчас вместо них декоративные CSS-текстуры; если владелец предоставит фото (с согласия клиентов), галерею стоит заменить на реальные снимки.
6. Домен и хостинг для публикации сайта — сейчас это локальные файлы.

## Не могу проверить
- Lighthouse/Core Web Vitals метрики — Node.js и связанные CLI-инструменты недоступны в этой среде, автоматический аудит производительности/accessibility не запускался.
- Рендеринг шрифтов Google Fonts (Fraunces, Work Sans) без доступа в интернет — подключены через `<link>`, но фактическая загрузка не протестирована оффлайн.
- Кроссбраузерное тестирование (Safari/iOS, старые версии браузеров) — визуально проверено только в одном браузерном движке через превью.
- Живое выполнение `script.js` (клик по мобильному меню, отправка формы записи, reveal-анимации) не удалось протестировать интерактивно: превью-песочница для этого пути рендерит файл как статический снимок без исполнения скриптов, а скриншоты браузерной панели были недоступны в этой сессии. HTML/CSS проверены визуально через текстовый рендер страницы, отсутствие ошибок в консоли и сверку `script.js` построчно (селекторы и id совпадают с разметкой, номер WhatsApp закодирован верно: 79852108806). Перед сдачей клиенту рекомендуется один раз открыть `index.html` в обычном браузере и вручную проверить мобильное меню и кнопку «Отправить в WhatsApp».
